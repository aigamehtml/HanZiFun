# HanZiFun 离线中文写字练习本生成器需求稿

## Demo

当前仓库包含一个最小可用 Demo：

- 纯 HTML/CSS/JavaScript，无构建步骤
- 内置 10 个示例字：人、口、日、月、水、火、山、田、木、永
- 支持田字格描红、米字格描红、笔顺分解 3 种模板
- 使用 SVG 渲染笔画、笔顺编号、起笔点和方向箭头
- 支持 A4 页面预览和浏览器打印 / 保存 PDF

本地试用：

```text
双击 index.html
```

或启动本地静态服务器：

```bash
python3 -m http.server
```

然后访问：

```text
http://localhost:8000
```

GitHub Pages 部署后可直接在线预览。

## 1. 产品目标

HanZiFun 是一个可离线运行的网页工具，用于帮助家长、老师为儿童生成中文写字练习本。

用户可以输入汉字、词语或短文，选择不同练字模板，系统自动生成适合 A5、A4、A3、Letter 纸张打印的练习页。练习页需要包含汉字示范、描红、空白练习格，以及最关键的笔顺展示。

最终用户可以直接通过浏览器打印，或保存为 PDF。

## 2. 使用场景

### 2.1 家长使用

家长输入孩子当天需要练习的生字，例如：

```text
日 月 水 火 山 石 田
```

选择“田字格 + 笔顺 + 描红”模板，生成 A4 练习页并打印。

### 2.2 老师使用

老师输入一课生字或词语，批量生成全班统一练习纸。

### 2.3 幼儿启蒙

用户选择大格模板，每页只练 2 到 4 个字，显示较大的笔顺分解和描红字。

### 2.4 小学生巩固

用户选择标准田字格，每页可容纳更多汉字，每个字包括示范、描红和空白书写格。

## 4. 核心功能

### 4.1 输入内容

内容来源支持两类：

- 手动输入
- 内置内容模板

#### 手动输入

用户可以输入：

- 单个汉字
- 多个汉字
- 词语
- 短句
- 古诗
- 课文生字列表

系统需要自动提取其中的中文汉字。

示例输入：

```text
春眠不觉晓，处处闻啼鸟。
```

系统提取：

```text
春 眠 不 觉 晓 处 闻 啼 鸟
```

可选设置：

- 保留重复字
- 自动去重
- 按输入顺序排列
- 按笔画数排列
- 按拼音排列
- 忽略非汉字字符
- 保留标点

#### 内置内容模板

产品需要提供内置内容模板，让家长和老师打开网页后不用自己准备文本也能快速生成练习纸。

第一版建议支持：

- 唐诗精选
- 三字经分段
- 小学常用字组
- 基础结构字组
- 常见词语组

内容模板按类别组织：

```text
唐诗精选：
静夜思、春晓、登鹳雀楼、咏鹅、悯农、望庐山瀑布、早发白帝城、绝句

启蒙经典：
三字经、百家姓、千字文、弟子规

小学常用：
一年级常用字、二年级常用字、数字汉字、自然词语、动物词语、季节词语

基础结构：
独体字、左右结构、上下结构、包围结构、横竖撇捺基础字
```

模板选择后的行为：

- 默认将模板内容填入输入框，替换当前内容
- 提供“追加”能力，允许老师组合多个模板
- 保留去重、排序、保留重复字等现有内容处理设置
- 唐诗模板可显示诗名和作者
- 三字经等长文本必须按段落拆分，不能一次塞完整篇

唐诗模板示例：

```text
春晓
唐 · 孟浩然

春眠不觉晓，
处处闻啼鸟。
夜来风雨声，
花落知多少。
```

三字经模板示例：

```text
三字经 · 第一段

人之初，性本善。
性相近，习相远。
苟不教，性乃迁。
教之道，贵以专。
```

第一版先按“全文拆字”生成练习内容。后续可以增加“只提取生字”模式。

### 4.2 模板选择

第一版正式产品建议支持以下模板。

#### 模板 A：标准田字格

适合小学生日常练习。

每个字包含：

- 拼音
- 示范字
- 描红字
- 空白练习格

#### 模板 B：米字格

适合控笔和结构练习。

每个字包含：

- 米字格
- 灰色描红
- 多个空白格

#### 模板 C：笔顺分解

适合学习新字。

每个字包含：

- 大号示范字
- 分步骤笔顺图
- 笔顺编号
- 起笔点
- 描红格
- 空白练习格

#### 模板 D：空白练习纸

适合自由练字、课堂发放、控笔练习和临摹。

该模板不依赖汉字输入，也不依赖笔顺数据。即使输入内容为空，也可以根据当前纸张和格子设置直接生成可打印页面。

支持内容：

- 田字格空白纸
- 米字格空白纸
- 自定义页数
- 自定义格子大小
- 自定义每行格子数
- 自定义每页行数
- 自定义线条颜色和辅助线深浅
- 可选页眉信息

#### 后续模板：拼音田字格

适合低年级。

每行包含：

- 拼音四线三格
- 汉字田字格
- 描红练习
- 空白练习

#### 后续模板：一页一字强化练习

适合难字重点训练。

每页一个字，包含：

- 大号笔顺图
- 基本信息
- 多行描红
- 多行临写
- 自评区

### 4.3 笔顺展示

这是核心功能。

每个汉字应支持：

- 正确笔顺
- 每一笔单独绘制
- 全字笔顺编号
- 起笔点标记
- 行笔方向箭头
- 分步笔顺图
- 当前笔深色、之前笔浅色
- 可选择是否显示笔顺编号
- 可选择是否显示箭头

显示方式：

#### 方式 1：完整字上标编号

在完整汉字上标出笔顺数字：

```text
1 2 3 4 ...
```

#### 方式 2：分步展示

例如“永”字 5 笔：

```text
第 1 步：只显示第 1 笔
第 2 步：显示第 1-2 笔
第 3 步：显示第 1-3 笔
...
```

#### 方式 3：当前笔强调

每个分步图中：

- 已完成笔画：浅灰
- 当前笔画：黑色或蓝色
- 未完成笔画：不显示

### 4.4 描红功能

描红字应支持：

- 灰色实心描红
- 空心描红
- 虚线描红
- 按笔画描红
- 可调透明度
- 可调大小

第一版优先实现：

- 灰色实心描红
- 空白练习格

### 4.5 格子样式

支持以下格子：

#### 田字格

- 外框实线
- 横中线虚线
- 竖中线虚线

#### 米字格

- 外框实线
- 横中线虚线
- 竖中线虚线
- 两条对角线虚线

#### 回宫格

- 外框实线
- 内框虚线或浅色线

#### 拼音格

- 四线三格
- 与汉字格上下对齐

样式设置：

- 格子大小
- 线条颜色
- 线条粗细
- 辅助线是否显示
- 每行格子数量
- 每页行数
- 空白纸页数

## 5. 页面与交互

### 5.1 主界面布局

建议分为左右两栏。

左侧为设置区：

- 输入内容
- 模板选择
- 纸张设置
- 字体/字形设置
- 笔顺设置
- 格子设置
- 恢复默认设置按钮
- 清空内容按钮
- 打印按钮

右侧为预览区：

- 所选纸张尺寸的页面预览
- 分页显示
- 缩放预览
- 当前页数

### 5.2 基础操作流程

1. 用户输入汉字内容
2. 选择模板
3. 调整设置
4. 系统实时更新页面预览
5. 用户点击“打印 / 保存 PDF”
6. 浏览器打开打印窗口
7. 用户选择打印机或保存为 PDF

所有设置项必须所见即所得实时生效，不应要求用户反复点击“生成”。

实时生效范围包括：

- 输入文字
- 模板切换
- 纸张大小
- 页面方向
- 页边距
- 格子大小
- 每行格子数
- 每页行数
- 每字练习次数
- 页眉模板
- 标题、姓名、班级、日期
- 拼音开关
- 笔顺编号开关
- 起笔点开关
- 方向箭头开关
- 描红透明度
- 空白纸页数

## 7. 数据需求

目标支持常用 3500 字。

根据 `hanzi-writer-data@2.0.1` 的粗略体积评估：

```text
全量 JSON：9575 字
原始 JSON 合计：约 22MB
npm 压缩包：约 12.8MB
3500 字 gzip 样本：约 3.95MB
```

因此 3500 字数据不适合直接打进首屏主包。正式版本采用按需加载策略。

加载策略：

- 主包只内置少量 Demo 字，保证首次打开快
- 用户输入文字后，按字加载对应笔顺 JSON
- 加载过的字缓存到浏览器本地
- GitHub Pages 放置完整 `data/characters/*.json`
- 离线版可以下载完整 `data` 文件夹使用
- 后续可提供“3500 常用字离线包”

如果某个字加载失败或没有数据，需要明确提示，不应静默丢失。

### 7.1 汉字笔顺数据

每个汉字需要包含：

```json
{
  "character": "永",
  "strokes": [
    "M ...",
    "M ...",
    "M ..."
  ],
  "medians": [
    [[0, 0], [100, 100]],
    [[120, 120], [180, 180]]
  ]
}
```

字段说明：

- `character`：汉字
- `strokes`：每一笔的 SVG path
- `medians`：每一笔的中线轨迹，用于起笔点和箭头
- `strokes.length`：笔画数

### 7.2 拼音数据

每个汉字需要包含：

```json
{
  "你": "ni3",
  "好": "hao3"
}
```

多音字第一版可以使用默认读音，后续支持用户选择。

### 7.3 字符元数据

可选：

```json
{
  "永": {
    "radical": "水",
    "strokeCount": 5,
    "structure": "独体字"
  }
}
```

## 8. 技术方案

### 8.1 前端技术

建议使用纯前端方案：

```text

```

- 绘制笔顺编号

## 10. 移动端与 PWA

HanZiFun 需要移动端友好，并支持添加到桌面，形成类似 App 的使用体验。

### 10.1 移动端目标

手机端不是简单“能打开”，而是需要：

- 布局适配手机屏幕
- 设置项容易点击和编辑
- 纸张预览不横向溢出
- 可添加到手机桌面
- 添加后以独立应用样式打开
- 首次加载后基础功能可离线打开
- 自动恢复上次设置

### 10.2 移动端布局

桌面端保持：

```text
左侧设置栏 + 右侧纸张预览
```

手机端建议改为：

```text
顶部应用栏
+ 中间纸张预览
+ 底部设置入口 / 设置抽屉
```

默认优先展示纸张预览，因为纸张是产品核心。设置项通过底部抽屉或分组面板进入。

推荐结构：

```text
┌────────────────────┐
│ HanZiFun      打印 │
├────────────────────┤
│                    │
│   缩放后的纸张预览  │
│                    │
├────────────────────┤
│ 内容 · 模板 · 设置  │
└────────────────────┘
```

移动端设置面板要求：

- 控件高度至少 44px
- 分组折叠展示，避免一次显示过长
- 打印按钮固定在容易触达的位置
- 不出现页面级横向滚动
- A5/A4/A3/Letter 都按比例缩放进屏幕宽度
- 横版纸张也必须完整可见
- 多页预览纵向滚动

### 10.3 PWA 添加到桌面

需要支持 Progressive Web App。

文件建议：

```text
manifest.webmanifest
service-worker.js
icons/
  icon-192.png
  icon-512.png
```

Manifest 关键配置：

```json
{
  "name": "HanZiFun",
  "short_name": "HanZiFun",
  "start_url": ".",
  "display": "standalone",
  "background_color": "#EEF2F6",
  "theme_color": "#176B87"
}
```

用户安装方式：

- iPhone：Safari 分享菜单 -> 添加到主屏幕
- Android Chrome：菜单 -> 添加到主屏幕 / 安装应用

### 10.4 PWA 离线缓存

Service Worker 应缓存：

- `index.html`
- `style.css`
- `app.js`
- `manifest.webmanifest`
- icons
- 内置 demo 数据
- 已经按需加载过的汉字数据

3500 字数据不应首次全部缓存。应按需缓存，并在后续提供“下载常用字离线包”能力。

### 10.5 移动端打印说明

手机浏览器打印体验不如桌面稳定，因此要求：

- 手机端支持预览和设置
- 支持系统分享 / 打印能力
- 在界面中提示桌面浏览器打印更稳定
- 后续可增强为先导出 PDF 文件，再分享或打印

- 米字格模板

## 13. 验收标准

MVP 完成后应满足：

- 断网后仍可正常打开和使用
- 输入汉字后能生成练习页
- 从内置内容模板能填入或追加练习内容
- 至少包含唐诗精选、三字经分段、小学常用字组
- 空白纸模板不输入汉字也能生成格子页
- A5 / A4 / A3 / Letter 打印尺寸正确
- 纵向 / 横向页面尺寸正确
- 至少支持 4 种模板
- 支持 3500 常用字按需加载
- 每个字能显示正确笔顺
- 不支持字有明确提示
- 笔顺编号清晰可见
- 描红字打印后清晰
- 田字格 / 米字格线条清楚但不干扰书写
- 浏览器保存 PDF 后内容不变形
- 页面不会依赖任何远程资源
- 所有设置实时生效
- 设置刷新页面后能自动恢复
- 手机端无页面级横向滚动
- 手机端纸张预览按比例缩放且完整可见
- 可通过 PWA 添加到桌面
- 添加到桌面后以 standalone 样式打开
- 首次加载后基础页面可离线打开

## 14. 技术风险

主要风险有：

- 笔顺数据质量不足
- 多音字拼音不准确
- 浏览器打印缩放导致尺寸偏差
- 不同浏览器打印效果不完全一致
- 笔顺编号自动放置可能遮挡笔画
- 大量汉字 SVG 导致页面卡顿
- 离线数据包体积较大
- 按需加载和离线使用之间需要清晰的资源组织
- `localStorage` 设置升级需要兼容旧版本
- 手机浏览器打印能力和桌面浏览器不一致
- PWA 在 iOS Safari 和 Android Chrome 的安装体验不同
- Service Worker 缓存策略需要避免缓存旧版本资源


## 16. 核心结论

HanZiFun 可以完全做成网页工具。关键技术是按需加载的本地笔顺数据、内置内容模板、SVG 笔画渲染、模板化排版、多纸张打印控制、所见即所得预览、移动端友好布局、PWA 离线缓存和浏览器本地设置保存。
