# HanZiFun 离线中文写字练习本生成器需求稿

## Demo

当前仓库包含一个最小可用 Demo：

- 纯 HTML/CSS/JavaScript，无构建步骤
- 内置 10 个示例字：人、口、日、月、水、火、山、田、木、永
- 支持田字格描红、米字格描红、笔顺分解 3 种模板
- 使用 SVG 渲染笔画、笔顺编号、起笔点和方向箭头
- 支持 A4 页面预览和浏览器打印 / 保存 PDF

本地试用：

```text
双击 index.html
```

或启动本地静态服务器：

```bash
python3 -m http.server
```

然后访问：

```text
http://localhost:8000
```

GitHub Pages 部署后可直接在线预览。

## 1. 产品目标

HanZiFun 是一个可离线运行的网页工具，用于帮助家长、老师为儿童生成中文写字练习本。

用户可以输入汉字、词语或短文，选择不同练字模板，系统自动生成适合 A4 打印的练习页。练习页需要包含汉字示范、描红、空白练习格，以及最关键的笔顺展示。

最终用户可以直接通过浏览器打印，或保存为 PDF。

## 2. 使用场景

### 2.1 家长使用

家长输入孩子当天需要练习的生字，例如：

```text
日 月 水 火 山 石 田
```

选择“田字格 + 笔顺 + 描红”模板，生成 A4 练习页并打印。

### 2.2 老师使用

老师输入一课生字或词语，批量生成全班统一练习纸。

### 2.3 幼儿启蒙

用户选择大格模板，每页只练 2 到 4 个字，显示较大的笔顺分解和描红字。

### 2.4 小学生巩固

用户选择标准田字格，每页可容纳更多汉字，每个字包括示范、描红和空白书写格。

## 4. 核心功能

### 4.1 输入内容

用户可以输入：

- 单个汉字
- 多个汉字
- 词语
- 短句
- 古诗
- 课文生字列表

系统需要自动提取其中的中文汉字。

示例输入：

```text
春眠不觉晓，处处闻啼鸟。
```

系统提取：

```text
春 眠 不 觉 晓 处 闻 啼 鸟
```

可选设置：

- 保留重复字
- 自动去重
- 按输入顺序排列
- 按笔画数排列
- 按拼音排列
- 忽略非汉字字符
- 保留标点

### 4.2 模板选择

第一版建议支持以下模板。

#### 模板 A：标准田字格

适合小学生日常练习。

每个字包含：

- 拼音
- 示范字
- 描红字
- 空白练习格

#### 模板 B：米字格

适合控笔和结构练习。

每个字包含：

- 米字格
- 灰色描红
- 多个空白格

#### 模板 C：笔顺分解

适合学习新字。

每个字包含：

- 大号示范字
- 分步骤笔顺图
- 笔顺编号
- 起笔点
- 描红格
- 空白练习格

#### 模板 D：拼音田字格

适合低年级。

每行包含：

- 拼音四线三格
- 汉字田字格
- 描红练习
- 空白练习

#### 模板 E：一页一字强化练习

适合难字重点训练。

每页一个字，包含：

- 大号笔顺图
- 基本信息
- 多行描红
- 多行临写
- 自评区

### 4.3 笔顺展示

这是核心功能。

每个汉字应支持：

- 正确笔顺
- 每一笔单独绘制
- 全字笔顺编号
- 起笔点标记
- 行笔方向箭头
- 分步笔顺图
- 当前笔深色、之前笔浅色
- 可选择是否显示笔顺编号
- 可选择是否显示箭头

显示方式：

#### 方式 1：完整字上标编号

在完整汉字上标出笔顺数字：

```text
1 2 3 4 ...
```

#### 方式 2：分步展示

例如“永”字 5 笔：

```text
第 1 步：只显示第 1 笔
第 2 步：显示第 1-2 笔
第 3 步：显示第 1-3 笔
...
```

#### 方式 3：当前笔强调

每个分步图中：

- 已完成笔画：浅灰
- 当前笔画：黑色或蓝色
- 未完成笔画：不显示

### 4.4 描红功能

描红字应支持：

- 灰色实心描红
- 空心描红
- 虚线描红
- 按笔画描红
- 可调透明度
- 可调大小

第一版优先实现：

- 灰色实心描红
- 空白练习格

### 4.5 格子样式

支持以下格子：

#### 田字格

- 外框实线
- 横中线虚线
- 竖中线虚线

#### 米字格

- 外框实线
- 横中线虚线
- 竖中线虚线
- 两条对角线虚线

#### 回宫格

- 外框实线
- 内框虚线或浅色线

#### 拼音格

- 四线三格
- 与汉字格上下对齐

样式设置：

- 格子大小
- 线条颜色
- 线条粗细
- 辅助线是否显示
- 每行格子数量
- 每页行数

## 5. 页面与交互

### 5.1 主界面布局

建议分为左右两栏。

左侧为设置区：

- 输入内容
- 模板选择
- 纸张设置
- 字体/字形设置
- 笔顺设置
- 格子设置
- 生成按钮
- 打印按钮

右侧为预览区：

- A4 页面预览
- 分页显示
- 缩放预览
- 当前页数

### 5.2 基础操作流程

1. 用户输入汉字内容
2. 选择模板
3. 调整设置
4. 点击“生成练习本”
5. 系统显示 A4 预览
6. 用户点击“打印 / 保存 PDF”
7. 浏览器打开打印窗口
8. 用户选择打印机或保存为 PDF

### 5.3 设置项

#### 内容设置

- 输入文本
- 是否去重
- 是否忽略非汉字字符
- 是否保留标点
- 排序方式

#### 模板设置

- 模板类型
- 每字练习次数
- 每页字数
- 是否显示标题
- 是否显示日期
- 是否显示页码

#### 笔顺设置

- 显示笔顺
- 显示笔顺编号
- 显示起笔点
- 显示方向箭头
- 分步图数量
- 当前笔颜色
- 已完成笔颜色

#### 打印设置

- 纸张：A4
- 方向：纵向 / 横向
- 页边距
- 打印缩放提示
- 是否显示裁切边界

## 6. A4 打印要求

必须保证打印尺寸准确。

### 6.1 页面尺寸

A4 纵向：

```text
210mm x 297mm
```

A4 横向：

```text
297mm x 210mm
```

### 6.2 CSS 打印规范

```css
@page {
  size: A4;
  margin: 10mm;
}

.page {
  width: 210mm;
  min-height: 297mm;
  page-break-after: always;
}
```

### 6.3 打印注意事项

页面需要提示用户：

- 打印缩放选择“实际大小”或“100%”
- 关闭浏览器默认页眉页脚
- 背景图形需要开启打印
- 保存 PDF 时选择 A4

## 7. 数据需求

### 7.1 汉字笔顺数据

每个汉字需要包含：

```json
{
  "character": "永",
  "strokes": [
    "M ...",
    "M ...",
    "M ..."
  ],
  "medians": [
    [[0, 0], [100, 100]],
    [[120, 120], [180, 180]]
  ]
}
```

字段说明：

- `character`：汉字
- `strokes`：每一笔的 SVG path
- `medians`：每一笔的中线轨迹，用于起笔点和箭头
- `strokes.length`：笔画数

### 7.2 拼音数据

每个汉字需要包含：

```json
{
  "你": "ni3",
  "好": "hao3"
}
```

多音字第一版可以使用默认读音，后续支持用户选择。

### 7.3 字符元数据

可选：

```json
{
  "永": {
    "radical": "水",
    "strokeCount": 5,
    "structure": "独体字"
  }
}
```

## 8. 技术方案

### 8.1 前端技术

建议使用纯前端方案：

```text
HTML + CSS + JavaScript
```

如果后续复杂度上升，可以使用：

```text
React / Vue / Svelte
```

第一版建议不用复杂框架，降低离线部署难度。

### 8.2 渲染技术

核心使用 SVG。

用途：

- 绘制汉字笔画
- 绘制田字格
- 绘制米字格
- 绘制笔顺编号
- 绘制起笔点
- 绘制箭头

优点：

- 打印清晰
- 可缩放
- 易于控制每一笔
- 适合导出 PDF

### 8.3 PDF 生成方式

第一版：

```text
浏览器打印 -> 保存为 PDF
```

后续增强：

- 使用 jsPDF 生成 PDF
- 使用 Puppeteer 批量生成 PDF
- 使用 Electron 打包桌面版

离线网页第一版不强制内置 PDF 库。

## 9. 离线要求

系统必须能在无网络环境使用。

### 9.1 不依赖 CDN

禁止使用：

```text
https://cdn...
Google Fonts
远程 JS 库
远程图片
远程 API
```

所有资源必须本地化。

### 9.2 数据本地化

汉字笔顺数据、拼音数据、字体文件都需要放在本地。

### 9.3 隐私要求

用户输入的文字不上传服务器。

## 12. 验收标准

MVP 完成后应满足：

- 断网后仍可正常打开和使用
- 输入汉字后能生成练习页
- A4 打印尺寸正确
- 至少支持 3 种模板
- 至少支持 100 个常用汉字笔顺数据
- 每个字能显示正确笔顺
- 笔顺编号清晰可见
- 描红字打印后清晰
- 田字格 / 米字格线条清楚但不干扰书写
- 浏览器保存 PDF 后内容不变形
- 页面不会依赖任何远程资源

## 13. 技术风险

主要风险有：

- 笔顺数据质量不足
- 多音字拼音不准确
- 浏览器打印缩放导致尺寸偏差
- 不同浏览器打印效果不完全一致
- 笔顺编号自动放置可能遮挡笔画
- 大量汉字 SVG 导致页面卡顿
- 离线数据包体积较大


第三阶段再做：

```text
课本字表
```

## 15. 核心结论

HanZiFun 可以完全做成离线网页。关键技术是本地笔顺数据、SVG 笔画渲染、模板化排版和 A4 打印控制。
